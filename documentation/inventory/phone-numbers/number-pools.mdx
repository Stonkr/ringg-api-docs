A pool is the answer to one question: does every call need to show the same <Tooltip tip="The number the person you call sees on their phone.">caller ID</Tooltip>? If not, a pool spreads a [campaign](/documentation/deploy/campaigns/create-a-campaign) or high-volume API calling across several [numbers](/documentation/inventory/phone-numbers/overview) and drops any that get [flagged as spam](/documentation/inventory/phone-numbers/overview#spam-flags-and-tags). Campaigns and API calls reference the pool's ID, so you add or swap numbers in one place without touching them.

In the dashboard: **Sidebar → Inventory → Numbers → Number Pools**.

### Which numbers you can add

| Number | Can join a pool? |
|---|---|
| Bought, imported or custom number | Yes |
| Test number | No. "Test numbers aren't listed. They're for trial calls and can't join a pool." |
| Number attached to an inbound agent | No. [Detach it](/documentation/inventory/phone-numbers/inbound-agent-number#detach-a-number) first. |
| Number in a pool with a campaign running | No, until the [campaign](/documentation/deploy/campaigns/manage-a-campaign) ends. |
| Number in another pool with no campaign running | Yes. It moves out of the old pool. |

## Use a pool in the dashboard

When you [create a campaign](/documentation/deploy/campaigns/create-a-campaign), the **Select number** card has two tabs: **Individual numbers** and **Number pool**. Choose **Number pool** and pick a pool. If you have none, the card shows "No number pools yet." with a **Create a pool** link.

## Use a pool with the API

Send `number_pool_id` to choose caller IDs from a pool. You need an [API key](/documentation/manage-account/api-key), the agent's ID ([Find an agent's ID](/documentation/build-agents/agents/agent-types#find-the-agent-id)) and the pool's ID (**Copy pool ID** on [the pool list](#the-pool-list)).

| Endpoint | Pool field |
|---|---|
| [Initiate Individual Call (Number Pool)](/api-reference/endpoint/calling/initiate-individual-call-v2) `POST /calling/v2/outbound/individual` | `number_pool_id`. Send at least one of `number_pool_id`, `from_number_id` or `from_number`; with a pool, the pool is used and the other field is ignored. |
| [Start Campaign (Number Pool)](/api-reference/endpoint/campaign/start-campaign-v2) `POST /campaign/v2/start` | `number_pool_id`, required with `agent_id` and `list_id`. |
| [Start Large Campaign Calls](/api-reference/endpoint/campaign/make-large-campaign-calls-async) `POST /campaign/make-call-async` | `number_pool_id` or `from_numbers`, exactly one. Both or neither returns `422`. |

A pool ID that doesn't exist returns `400` "Number pool not found"; a pool with no numbers returns `400` "Number pool has no available numbers". To find which pool a number is in, read `number_pool_id` from [Get Workspace Numbers](/api-reference/endpoint/numbers/get-workspace-numbers).

## How a pool picks the number

Ringg rotates through the pool's numbers in turn (round robin), skipping any number flagged as spam from the moment it is flagged. Each retry of a call picks again, so a contact isn't tied to one number. If every number in the pool is flagged, Ringg still dials, from the number that was flagged longest ago.

## Auto purchase

With **Auto purchase** on, the pool buys one replacement number from Ringg's account when one of its numbers is flagged as spam, and adds it to the same pool. The replacement comes from the flagged number's own country; the **Replacement country** you chose when creating the pool is used only when that country can't be worked out or has no numbers for sale. You can turn the switch on or off later on the pool page.

The flagged number stays in the pool, is skipped, and keeps its rental. The replacement is billed like any Ringg number you buy; the pool itself costs nothing. If your balance is too low, or the country needs international calling that your workspace doesn't have, nothing is bought. Workspace admins get an email when a replacement is bought.

## The pool page

The pool page (`/numbers/<pool ID>`) shows the name, description, the **Auto purchase** switch, **Add number** and a delete button. Its table has **ID**, **Country**, **Mobile number**, **Provider**, **Added on** and **Tags**, plus a **Spam** chip on flagged numbers.

- **Add numbers:** click **Add number**, tick numbers in **Add numbers to _pool_**, then click **Add**.
- **Remove a number:** use the row's remove button and confirm **Remove**. "The number stays in your workspace and can be added to another pool."
- **Tags:** edit a number's tags from its row.

## The default pool

Your workspace has one pool marked **Default**, which can't be deleted. Numbers land in it in two cases: when you [detach them from an inbound agent](/documentation/inventory/phone-numbers/inbound-agent-number#detach-a-number), and when their [pool is deleted](#delete-a-pool). New numbers don't; add them to a pool yourself.

## Restrictions while a campaign runs

While a campaign is using a pool, the pool shows **Active** and is frozen ("Campaign in progress — pool is frozen"):

- **Add number**, remove and delete are disabled.
- You can't drag numbers into or out of it ("Locked — campaign running").
- The **Auto purchase** switch still works.

## Delete a pool

Open the pool, click the delete button and confirm with **Delete pool**. The pool is archived and its numbers move to your [default pool](#the-default-pool). This can't be undone.

<Check>
You see "Pool archived" with the number of numbers moved.
</Check>

You can't delete a pool while a campaign is using it.

## Troubleshooting

<AccordionGroup>
  <Accordion title="All numbers are in use">
    The picker hides every number that [can't join a pool](#which-numbers-you-can-add). Detach the number from its agent, wait for the campaign to end, or [buy a number](/documentation/inventory/phone-numbers/buy-or-import-a-number).
  </Accordion>
  <Accordion title="No purchased numbers">
    "Test numbers are for trial calls and can't join a pool. Buy or import a number first." See [Buy or import a number](/documentation/inventory/phone-numbers/buy-or-import-a-number).
  </Accordion>
  <Accordion title="I can't add or remove numbers">
    The pool is **Active**: a campaign is using it ([restrictions](#restrictions-while-a-campaign-runs)). Wait for the [campaign](/documentation/deploy/campaigns/manage-a-campaign) to end.
  </Accordion>
  <Accordion title="My pool is greyed out in the campaign form">
    The pool has no numbers. Add at least one number to it.
  </Accordion>
</AccordionGroup>
