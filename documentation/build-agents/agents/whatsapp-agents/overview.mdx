A WhatsApp agent is one of the four [agent types](/documentation/build-agents/agents/agent-types#agent-types-by-channel), next to outbound, inbound and webcall. It has the same prompt, knowledge base, custom variables and tools as a voice agent, but it replies in WhatsApp messages on a WhatsApp Business number you connect through Meta. When a customer calls that number from WhatsApp, the same agent answers by voice; it can't place WhatsApp calls.

Use it when customers already reach you on WhatsApp, or to follow up a call in writing. You don't need a WhatsApp agent to *send* a WhatsApp message from a voice agent: once WhatsApp Business is connected, any agent can send a template or text through the [WhatsApp tools](/documentation/build-agents/customize-agent-behaviour/tools/whatsapp-tools#on-call).

## How a chat runs

1. A customer messages your WhatsApp Business number, or your backend [messages them first](/documentation/deploy/whatsapp/start-a-conversation) with a template.
2. The agent attached to that number opens a chat. Pre-call tools run, then the agent replies from its prompt, knowledge base and on-call tools.
3. The chat closes when the agent calls **End Chat** or the customer goes quiet for the agent's idle timeout ([session timeouts](/documentation/build-agents/agents/whatsapp-agents/create-an-agent#when-a-chat-opens-and-closes)). Post-call tools and analysis then run, and each stage can notify your [webhook](/documentation/build-agents/customize-agent-behaviour/webhooks/whatsapp-chat-events#whatsapp-chat-events).

## WhatsApp compared with voice

| | Voice agent | WhatsApp agent |
|---|---|---|
| Number | Telephony number ([Numbers](/documentation/inventory/phone-numbers/overview)) | Registered WhatsApp Business number |
| Structure | [Single-prompt or multi-prompt](/documentation/build-agents/agents/agent-types#agent-types-by-build-style) | Single-prompt only |
| Webhook events | `call_*`, `recording_completed`, analysis events | `chat_completed`, analysis events |
| Conversations | **Logs → Phone** | **Logs → WhatsApp** |
| [Analytics](/documentation/monitor/analytics) | Yes | No, Analytics covers calls only |

## Good to know

<AccordionGroup>
  <Accordion title="Why a template is needed after 24 hours">
    WhatsApp delivers free-form text only within 24 hours of the customer's last message. Outside that window only an approved template goes through. That is why **Send WhatsApp Text** is an on-call tool only, while **Send WhatsApp Template** also works post-call.
  </Accordion>
  <Accordion title="How replies are formatted">
    WhatsApp has its own markup: `*bold*`, `_italic_`, `~strikethrough~`, and lists that start with `- `. It has no headings, tables or Markdown links. The WhatsApp agent template already tells the model this; keep those rules if you rewrite the prompt.
  </Accordion>
</AccordionGroup>
