## Integration tools

An Integration tool runs an action on an app account connected to your workspace, such as creating a calendar event, appending a sheet row or posting to Slack. Which tools each app offers comes from Ringg. For WhatsApp's send-template and send-text tools, see [WhatsApp on-call tools](/documentation/build-agents/customize-agent-behaviour/tools/whatsapp-tools#on-call).

<Steps>
  <Step title="Pick the account">
    Click **Integration** in the side panel. **Select an integration** lists each connected app; expand one and pick the account. An expired account shows **Reconnect** instead until it is re-authorized on the sidebar **Tools** page.
  </Step>
  <Step title="Bind the parameters">
    Pick a tool from the account's list. Each parameter takes a **Static**, **Variable** or **JQ** value, plus **Dynamic** on-call, the same [sources](/documentation/build-agents/customize-agent-behaviour/tools/api-tools#parameter-sources) as an API tool. **Add test value** gives a sample for the run.
  </Step>
  <Step title="Run, then import">
    Click **Run**. **Import** is disabled until the run returns a response, so you always see the real result before the tool goes on the agent.
    <Check>
    The tool appears in the phase's list. Its card has a pencil (edit the bindings, **Run** again, then **Save**) and a bin (**Delete integration tool**, with a confirmation).
    </Check>
  </Step>
</Steps>
