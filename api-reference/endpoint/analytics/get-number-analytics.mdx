openapi: get /analytics/number-analytics
---

Break analytics down by phone number. Use this to compare caller ID performance, monitor BYOT numbers, and identify numbers with poor pickup or completion rates.

## Useful filters

- `start_date` and `end_date` for reporting windows.
- `agent_id` to compare numbers used by one assistant.
- `bulk_list_id` to compare numbers inside one campaign.

## How to act on results

If one number underperforms, check number assignment, telephony provider health, calling hours, and recipient region fit.
