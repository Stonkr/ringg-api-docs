The [number pool](/documentation/inventory/phone-numbers/number-pools) rotates numbers and skips ones flagged as spam.

## Caller number

Send at least one of these. With `number_pool_id`, Ringg picks the number from the pool and ignores the other two. Without a pool, outbound numbers set on the agent version are used before `from_number_id` or `from_number`.

| Field | When to use it |
|---|---|
| `number_pool_id` | Ringg picks the number from the pool. Copy the ID with **Copy pool ID** on the **Number pools** page. |
| `from_number_id` | A specific workspace number, from [List workspace numbers](/api-reference/endpoint/numbers/get-workspace-numbers). |
| `from_number` | A specific number written out with country code. |

```json
{
  "name": "John Doe",
  "mobile_number": "+919876543210",
  "agent_id": "your-agent-id",
  "number_pool_id": "your-number-pool-id",
  "custom_args_values": {
    "callee_name": "John",
    "order_id": "ORD-1042"
  }
}
```

`name`, `mobile_number`, `agent_id`, `custom_args_values`, `smart_formatter`, `call_config`, `version_id`, `purpose`, `call_validity_hours` and `call_deadline` work as on [Initiate individual call](/api-reference/endpoint/calling/initiate-individual-call). The response's `data.call_id` identifies the call everywhere else.

## Troubleshooting

As for [Initiate individual call](/api-reference/endpoint/calling/initiate-individual-call#troubleshooting), plus:

| Symptom | Check |
|---|---|
| `422` | No caller number source, or both `from_number_id` and `from_number`. |
| `400` | The pool does not exist (`Number pool not found`) or has no usable number (`Number pool has no available numbers`). |
