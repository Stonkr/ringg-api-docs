Each item has a `file_id`, which is the ID [Edit knowledge base](/api-reference/endpoint/kb/edit-knowledge-base) takes to remove it.

## Notes

- Poll this endpoint after creating or editing until `status` is `completed`. Large files or many URLs can take several minutes.
- Files carry `filename`, `file_type` and `file_size` (bytes); URLs carry `url`; FAQs carry `content` with the question and answer.
