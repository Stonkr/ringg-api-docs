Add balance first ([Billing](/documentation/manage-account/billing)), then call it with the `bulk_list_id` from [upload status](/api-reference/endpoint/campaign/get-large-campaign-upload-status). When the response's `status` is `draft`, [start calls](/api-reference/endpoint/campaign/make-large-campaign-calls-async) again with the same `bulk_list_id`; there is no need to upload the list again.

If the balance is still short, `status` stays `insufficient_balance` and the response gives `required_credits` and `additional_balance_required`. A campaign in another status, or with no contacts or agent, returns `400`. [Get all campaigns](/api-reference/endpoint/campaign/get-all-campaigns) runs the same check on every `insufficient_balance` campaign it lists.
