`list_id` is the one returned by [Upload campaign contact list](/api-reference/endpoint/campaign/upload-campaign-contact-list); `agent_id` is the agent the list was uploaded for. Copy `number_pool_id` with **Copy pool ID** on the **Number pools** page ([Number pools](/documentation/inventory/phone-numbers/number-pools)). `email_completion_user_ids` are workspace user IDs from [List workspace users](/api-reference/endpoint/workspace/list-workspace-users).

```json
{
  "agent_id": "your-agent-id",
  "list_id": "123e4567-e89b-12d3-a456-426614174000",
  "number_pool_id": "your-number-pool-id"
}
```

The response, the balance requirement and the errors are the same as for [Start campaign](/api-reference/endpoint/campaign/start-campaign).
