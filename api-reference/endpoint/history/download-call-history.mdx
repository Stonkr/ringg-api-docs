The response only confirms the export was queued: `{"message": "Call history export has been queued. You will receive an email shortly."}`. The download link arrives by email; large exports take several minutes.

## Notes

- `call_type` is `inbound`, `outbound` or `webcall`. The export covers every call that matches the filters.
- `include_analysis=true` adds the platform and [Advanced Analysis](/documentation/build-agents/customize-agent-behaviour/advanced-analysis) results.
- The CSV holds call details, status and timestamps, agent and campaign, transcript and recording links, and custom variables.
- The emailed link is valid for 7 days and downloads a ZIP with one CSV.
- Recording links in the export may expire; fetch a fresh link from [Get call details](/api-reference/endpoint/history/get-call-details).
- `409` means the same export is already running; `429` means too many exports are running, so try again later.
