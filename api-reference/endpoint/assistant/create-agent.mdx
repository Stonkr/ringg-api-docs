Use it when your product sets up agents for its own customers from a template; for a one-off agent, the [dashboard](/documentation/build-agents/agents/create-an-agent) is quicker and also builds multi-prompt agents.

The response returns the new agent's ID as `data.id`. Store it: calls and campaigns need it as `agent_id`.

## Prompt sections

The prompt fields become the agent's prompt sections, in this order:

| Field | Section in the dashboard |
|---|---|
| `introduction_and_objective` | Objective |
| `response_guidelines` | Response Guidelines |
| `task` | Conversation Script; `sample_conversations` is added at its end |
| `faq` | FAQs (empty when `faq` is left out) |

`intro_message` becomes the agent's first message.

`primary_language` and `secondary_language` accept `en-US`, `en-GB`, `en-AU`, `en-IN`, `hi-IN`, `ta-IN`, `te-IN`, `bn-IN`, `mr-IN`, `kn-IN`, `ms-MY`, `zh-CN`, `od-IN`, `pa-IN` and `my-MM`. The voice must support the language, or the request returns `400` with code `VOICE_LANGUAGE_MISMATCH`.

## Call settings

`call_config` sets how the agent's calls behave. Every key is optional; leave one out to keep its default.

| Field | What it controls | Default |
|---|---|---|
| `call_time` | Daily calling window: `call_start_time` and `call_end_time` (`HH:MM`, 24-hour) in `timezone` | `09:00`–`21:00`, `Asia/Kolkata` |
| `max_call_length` | Hard cap on call length, in seconds (10–3600) | `240` |
| `idle_timeout_warning` | Seconds of caller silence (0–600) before the agent asks if they are still there; `0` turns the check-in off | `5` |
| `idle_timeout_end` | Seconds of caller silence (1–600) before the call ends; must be greater than `idle_timeout_warning` | `10` |
| `noise_filter_config` | Noise cancellation on the caller's audio: `filter_noise` on/off, `noise_suppression_level` 0–100 | off, `80` |
| `voicemail` | `detect` voicemail, then `action`: `end`, `summarise`, or `static_message` (speaks the `static_message` text); `retry` re-queues the call | detect on, `end`, retry on |
| `background_audio_config` | Ambient track under the agent's voice: `audio_id` (only `office_ambience`) and `volume` from `0.0` to `1.0` | off |
| `mute_during_intro` | `true`: the caller cannot interrupt the first message | `true` |

```json
{
  "agent_name": "EMI reminder",
  "introduction_and_objective": "You are Asha, calling Acme Lending customers about an upcoming EMI.",
  "response_guidelines": "Be polite and brief. Confirm the due date before ending the call.",
  "task": "Remind the customer of the EMI due date and amount, and note if they want a callback.",
  "primary_language": "en-IN",
  "voice_id": "your-voice-id",
  "intro_message": "Hello, this is Asha from Acme Lending.",
  "call_config": {
    "call_time": { "call_start_time": "10:00", "call_end_time": "18:30", "timezone": "Asia/Kolkata" },
    "max_call_length": 300,
    "idle_timeout_warning": 8,
    "idle_timeout_end": 20,
    "voicemail": { "detect": true, "action": "end", "retry": true },
    "mute_during_intro": false
  }
}
```

Get `voice_id` from [List voices](/api-reference/endpoint/assistant/get-assistant-voices).

### Calling window

Outbound calls placed outside the window wait for the next opening, and so do retries. A campaign or an individual call can set its own window instead. The window may cross midnight: `22:00` to `06:00` is valid.

`timezone` accepts any IANA zone, such as `America/New_York`, `Europe/London`, `Asia/Dubai`, `Australia/Sydney` or `UTC`.

<Warning>
Use the `Region/City` form. `IST`, `PST` and `CST` are rejected. `EST`, `MST`, `HST` and `GMT` are accepted but never change for daylight saving, so an agent on `EST` calls an hour late for most of the year compared with `America/New_York`.
</Warning>

### Validation rules

The request fails, rather than the agent's later calls, when:

- a time is not zero-padded 24-hour (`09:00` works, `9:00` and `9:00 AM` do not);
- `idle_timeout_warning` is not less than `idle_timeout_end`;
- `background_audio_config.volume` is outside `0.0`–`1.0` (send `0.5`, not `50`).

## Notes

- To change call settings after creation, use `edit_call_config` on [Edit agent settings](/api-reference/endpoint/assistant/edit-assistant), or [Call settings](/documentation/build-agents/customize-agent-behaviour/call-settings) in the dashboard. `PATCH /public/agent/{agent_id}` (Update Agent) changes the prompt fields, language, voice, first message, type and variables, but not `call_config`.
- Before running a campaign, check the new agent with one [individual call](/api-reference/endpoint/calling/initiate-individual-call).
