Pass the chosen voice's `id` as `voice_id` when you [create an agent](/api-reference/endpoint/assistant/create-agent) or change its voice.

## Notes

- A voice works only in the languages listed in its `languages`. Pairing a voice with a language it does not support returns `400`.
