The agent is returned under `agents` as an object. Agent-level fields, such as `agent_display_name`, `agent_type` and `active_agent_version_id`, sit at the top; each version's language, voice, prompt (`agent_config`), tools, knowledge bases, `call_config` and `event_subscriptions` sit under `version_details`, keyed by version ID. For an outbound-inbound agent, add `type=inbound` to get its inbound settings.

A `404` means no agent with that ID exists in the workspace that owns the API key. Use it to check that an `agent_id` stored in your system still points at the agent you expect, for example after a call behaved unexpectedly.
