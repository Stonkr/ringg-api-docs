## Notes

- Without `limit`, every agent is returned. `search` filters by name.
- Each agent lists its `versions` (`version_id`, `version_slug`, `is_archived`). Prompt, voice and other settings are not included; use [Get agent](/api-reference/endpoint/assistant/get-assistant-by-id).

- An agent's ID does not change when the agent is edited, so look it up once during setup and store it rather than fetching it before every [call](/api-reference/endpoint/calling/initiate-individual-call) or [campaign](/api-reference/endpoint/campaign/upload-campaign-contact-list).
- For one agent's full configuration, call [Get agent](/api-reference/endpoint/assistant/get-assistant-by-id).
