---
openapi: post /workspace/sub
---

Create a new Ringg Space under the primary workspace that owns the API key. The Ringg Space starts empty: no balance or credit limit, no concurrency, no assistants, and no API key.

## When to use

- Onboarding a new client, brand, or team that needs its own isolated assistants, numbers, and call history.
- Automating tenant provisioning from your own admin system.

## Request parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `name` | string | Yes | Display name, 1 to 100 characters. Surrounding whitespace is trimmed; a blank name is rejected. |

## Integration notes

- Authenticate with the **primary** workspace's API key. A Ringg Space's key returns `400`.
- Store the returned `sub_workspace.id`; every allocation call needs it.
- The first Ringg Space you create turns the primary into a family in **individual** billing mode. Contact Ringg support if the family should use common billing instead.
- Every member of the primary automatically gets access to the new Ringg Space.
- The response never contains an API key. See [Ringg Spaces](/api-reference/endpoint/sub-workspace/overview#create-an-assistant-inside-a-ringg-space) for how to get one.

## Error responses

- **400**: `Sub-workspaces cannot have their own sub-workspaces.` — the key belongs to a Ringg Space.
- **401**: Invalid or missing API key.
- **403**: `Sub-workspaces are not enabled for this workspace.`
- **422**: Missing or blank `name`, or a name longer than 100 characters.

## Example

```bash
curl --request POST "https://prod-api.ringg.ai/ca/api/v0/workspace/sub" \
  --header "X-API-KEY: $RINGG_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{ "name": "Mumbai Collections" }'
```

## After creation

Give the Ringg Space capacity with [Allocate Concurrency](/api-reference/endpoint/sub-workspace/allocate-concurrency) and, in an individual family, a [credit limit](/api-reference/endpoint/sub-workspace/reallocate-credit-limits) or [balance](/api-reference/endpoint/sub-workspace/reallocate-credit-balances). Then generate its API key in the dashboard and [create an assistant](/api-reference/endpoint/assistant/create-agent) with that key.
