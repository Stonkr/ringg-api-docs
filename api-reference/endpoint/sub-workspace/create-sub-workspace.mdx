Use it for a client, brand or team that needs its own agents, numbers and call history. The Ringg Space's default agents and telephony are set up for it, and its currency, account type and billing plan are copied from the primary.

## Notes

- Store the returned `sub_workspace.id`; every allocation call needs it.
- The first Ringg Space you create turns the primary into a family in individual billing mode. Contact Ringg support if the family should use common billing instead.
- Every member of the primary automatically gets access to the new Ringg Space.

## Errors

- `400`: `Sub-workspaces cannot have their own sub-workspaces.` — the key belongs to a Ringg Space that has Ringg Spaces enabled.
- `401`: Invalid or missing API key.
- `403`: `Sub-workspaces are not enabled for this workspace.` — Ringg Spaces are not enabled on the primary, or the key belongs to a Ringg Space.
- `422`: Missing or blank `name`, or a name longer than 100 characters.

## After creation

Give the Ringg Space capacity with [Allocate Concurrency](/api-reference/endpoint/sub-workspace/allocate-concurrency) and, in an individual family, a [credit limit](/api-reference/endpoint/sub-workspace/reallocate-credit-limits) or [balance](/api-reference/endpoint/sub-workspace/reallocate-credit-balances). The response never contains an API key: generate one in the dashboard ([Ringg Spaces](/documentation/manage-account/ringg-spaces/ringg-spaces-by-api#manage-the-family-by-api)), then [create an agent](/api-reference/endpoint/assistant/create-agent) with that key.
