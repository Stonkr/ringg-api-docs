## Notes

- A `401` means the key is wrong or was regenerated. Get the current key from the workspace owner ([API key](/documentation/manage-account/api-key)).
- Check `name` before storing a key: each workspace and each [Ringg Space](/documentation/manage-account/ringg-spaces/overview) has its own key.
