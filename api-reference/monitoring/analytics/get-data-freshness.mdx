Show `data_as_of` as a "data as of" label. `version` changes whenever new data lands, so refetch only when it differs from the last value you saw.

## Notes

- `data_as_of` and `lag_seconds` are `null` and `version` is `0` before your workspace has any analytics data.

## Errors

- `401`: `X-API-KEY` is missing or invalid.
