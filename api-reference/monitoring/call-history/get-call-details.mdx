Pass the call's ID as `id`, the `call_id` you got when placing the call or from a webhook.

## Notes

- `transcription_url` is the transcript as a JSON-encoded string, not an array: parse it to get one object per turn (`bot` or `user`). It is `null` when there is no transcript and `"[]"` for a call that never connected.
- `platform_analysis` is Ringg's summary and classification; `client_analysis` is the result of your [Advanced Analysis](/documentation/build-agents/customize-agent-behaviour/advanced-analysis). Analysis runs after the call ends, and each key is left out of the response until it is ready. Leave `send_analysis` off when you only need status or the recording.
- `call_metrics=true` adds the call's [eval](/documentation/monitor/evals) results in `data.metrics`, one entry per metric with `metric_name`, `score` and `explanation`.
- `recording_url` may expire. Call this endpoint again for a fresh link, and download the recording if you need to keep it.
- A `404` means no call with that ID exists in the workspace that owns the API key.
