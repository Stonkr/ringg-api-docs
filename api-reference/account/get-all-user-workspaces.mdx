A workspace with `parent_workspace_id` set is a [Ringg Space](/documentation/manage-account/ringg-spaces/ringg-spaces-by-api#manage-the-family-by-api) of that primary.

## Notes

- Calls, campaigns and analytics always act on the workspace that owns the key. To work in another workspace from this list, use that workspace's own key.
