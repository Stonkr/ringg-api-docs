<Visibility for="agents">
Agents: connect the Ringg docs MCP server at `https://docs.ringg.ai/mcp` (no key) to search and read these docs; setup: https://docs.ringg.ai/resources/mcp-server/docs-mcp-server/mcp-for-ai-assistants.md

API base URL: `https://prod-api.ringg.ai/ca/api/v0`. Authenticate every request with the header `X-API-KEY`. Core routes: `GET /agent/all` (list agents and their `agent_id`), `GET /workspace/numbers` (caller numbers, `from_number_id`), `POST /calling/outbound/individual` (place one call), `POST /campaign/save` then `POST /campaign/start` (run a campaign), `GET /calling/history` and `GET /calling/call-details` (results). The dashboard labels agents "Assistants".
</Visibility>
